# CMS TOTP Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add password plus authenticator login and lightweight enrollment.
**Architecture:** Extend the existing Auth class with serialized private state updates; local QR generation and existing CSRF-protected API. No database.
**Tech Stack:** Node.js, OTPAuth, qrcode, existing vanilla UI.
**Spec:** ../specs/2026-10-29-cms-totp-design.md (approved)

## Global Constraints

Six digits, 30 seconds, bounded clock tolerance; no secret logging. Existing accounts remain usable before enrollment. Preserve password hashing, invalidate sessions on enrollment/disable, preserve MFA on password reset. Explicit offline reset only.

## Review Focus

Concurrent code replay, restart replay, expired enrollment, stale sessions, password reset preserving enrollment.
